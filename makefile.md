| Command           | Purpose                 |
| ----------------- | ----------------------- |
| `make`            | Default build + run     |
| `make compile`    | Compile only            |
| `make run`        | Run simulation          |
| `make clean`      | Remove build files      |
| `make mac`        | Compile MAC block only  |
| `make activation` | Compile activation only |
| `make full`       | Compile full TPU        |
| `make waves`      | Open waveform           |
